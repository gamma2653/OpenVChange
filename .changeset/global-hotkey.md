Add a keyboard shortcut that switches the effects on and off from anywhere, also while a game or a call has the focus. Set it under Advanced Settings by clicking the field and pressing the keys, for example Ctrl+Shift+F9. None is set by default. Letters and digits need Ctrl, Alt, or the Windows key; function keys work on their own. The shortcut is remembered between launches. Windows only.
