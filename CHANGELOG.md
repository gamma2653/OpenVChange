# openvchange

## 0.2.0

### Minor Changes

- 628636e: Add built-in presets and a list to choose them from: Neutral, Clean voice, Radio announcer, Telephone, Deep voice, Giant, Higher voice, and Chipmunk. The list shows which preset is in use and changes to Custom as soon as a setting is changed. Saving and loading your own preset files works as before.
- 8b171d4: Add a Refresh button next to the device lists. Devices plugged in after the app started used to stay invisible until it was restarted. The selected devices are kept across a refresh and across the "Show all devices" filter, and when all devices are shown, each entry now says which audio interface it belongs to, so identical names can be told apart.
- 5f72787: Add formant control. Shifting the pitch used to shift the resonances of the voice along with it, which is what makes a shifted voice sound like a tape played at the wrong speed. The new "Keep formants when shifting pitch" option moves them back, and the new Formant slider moves them on their own: down sounds like a larger person, up like a smaller one. The Deep voice, Giant, and Higher voice presets now use both. While formant control is in use it adds about 20 ms of delay. Both settings are off by default, so existing presets sound as before.
- ab9007f: Add a keyboard shortcut that switches the effects on and off from anywhere, also while a game or a call has the focus. Set it under Advanced Settings by clicking the field and pressing the keys, for example Ctrl+Shift+F9. None is set by default. Letters and digits need Ctrl, Alt, or the Windows key; function keys work on their own. The shortcut is remembered between launches. Windows only.
- 254b03e: Replace the level display with proper meters. There is now one for the input and one for the output, both on a decibel scale from -60 dB to full scale, with a marker that holds the highest recent peak and a readout in dB. A red light on the input meter shows that the microphone signal is clipping. A red light on the output meter shows that the effects are pushing the signal past full scale, which is when it starts to distort.
- bf32d42: Remember the chosen devices and every effect setting between launches. They used to reset each time the app started. Devices are remembered by name, so they are found again even when Windows lists them in a different order. If a device is no longer connected, the status line says so. The settings are kept in `settings.json` in the OpenVChange folder under your application data folder.

### Patch Changes

- 650e627: Fix the de-esser. It used to turn down the whole signal, voice included, by the full reduction in a single step whenever sibilance crossed the threshold. It now turns down only the band from 5 to 8 kHz, by as much as that band exceeds the threshold and at most by the reduction setting, and it does so gradually. Presets that use the de-esser will sound different.
- a2f3e00: Halve the size of the download. The executable is now about 34 MB, down from 68 MB, and opens about half a second sooner. The filters that needed the SciPy library now run on code of our own, which produces the same sound.
- 6abacbb: Give the app an icon, shown on the executable, in the title bar, and in the taskbar. The executable now also carries its name, description, and version, which Windows shows under Properties, and the version is shown at the bottom of the Advanced Settings tab.
- 54bf967: Fix the expander/gate. It judged the level from single samples, so even a signal well above the threshold was turned down by 5 dB or more. It now measures the level properly and leaves such signals untouched. Attack and release were also the wrong way round: the gate took over 100 ms to open, cutting off the start of words, and snapped shut in 20 ms. Attack now sets how fast the gate opens and release how fast it closes. Presets that use the expander will sound different, and may want a lower threshold.
- 041e403: Make the expander, compressor, and de-esser about twenty-five times faster. With every effect enabled, the engine now needs about 3% of the time available for each buffer instead of about 75%, which removes the dropouts and crackle that heavy presets caused.
- 773194d: Make pitch shifting about fifty times faster. It used to take most of the time available for each buffer, and more than all of it with eight voices, which caused dropouts and crackle. The sound is unchanged.
- a3debde: Make the delay, gain, and filter stages much faster. The delay and gain no longer process audio one sample at a time, and filters are redesigned only when their settings change. The sound is unchanged.
- 5087cd2: Check presets before using them. A preset with a wrong value, such as text where a number belongs, is now refused with a message that names the setting, and nothing from it is applied. Values outside a slider's range are brought into range and mentioned. Failures to read or write a preset file are reported in the status line. Loading a preset while audio is running no longer changes the buffer size or the number of pitch voices under the running stream, which could break pitch shifting; those two settings take effect at the next start.
- 3bec88d: Show audio failures instead of hiding them. If the stream cannot be started, the status line now says why and the window stays ready for another attempt, where it used to read "Running" with no sound. If an effect fails while running, the output goes silent and the stream stops with a message. It used to pass the unprocessed microphone signal through without any indication.
